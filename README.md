# NidecQR - Ứng dụng Quản lý Tham gia qua QR Code

Ứng dụng Android để quản lý việc tham gia/không tham gia của nhân viên thông qua quét mã QR, hỗ trợ thiết bị Zebra.

## Đang phát triển...

Ứng dụng đang được xây dựng với các tính năng:
- ✅ Quét QR Code
- ✅ Quản lý điểm danh
- ✅ Database SQLite
- ✅ Hỗ trợ Zebra Scanner
- ✅ Báo cáo và Export Excel
